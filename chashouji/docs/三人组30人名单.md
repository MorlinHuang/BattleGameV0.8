# 档 3 三人组：两边各 30 人、10 组（2026-09-29 夜定稿）

用户原话："把闺蜜和哥们总量分别扩充到30个角色，3个一组你来组合。角色极大丰富起来，角色的辨识度要非常明确，一眼就能看出是什么，
年龄跨度大一点，80、90、00后都有代表人物……要细致的做动作和特效，人物不能太死板，不能完全2d不动的出来，手臂身体该有的简单动作需要有，
攻击特效和道具细化，如果做3d转2d效果好的道具就做……对细节的要求要高，看起来是自然的流畅的，要往帧动画方向做，看着像精致的动画而非粗糙的贴图。"

## 通用规矩（沿用，别破）
- **借梗不写原名**：只留一眼认人的特征（发型、标志服装配色、标志道具、标志动作），细节重新设计；提示词里不写作品名、角色名。
- **都是成年人**：原型是小孩的一律不用或只借大人角色。服装尺度用户定（闺蜜延续比基尼 / 性感路线可以，用户拍板过）。
- **哥们打女生、闺蜜打男生；哥们在右、闺蜜在左**（哥们朝左、闺蜜朝右）。
- **三个槽位互不重叠**（trio.js 顶部注释）：
  - 上方：闺蜜在左上、哥们在右上，都在男女主头顶以下；HUD 和中上方留给档 4、出场视频。
  - 后排地面：在自己主角身后。
  - 前景地板：在两个下角、主角脚以下，y ≤ 1334，1334 以下直播时被评论区盖住。
- 攻击命中走 main.js `impact` + RECIPE；**打中的反馈要看得出是这件东西**：玫瑰出花瓣、篮球弹开、胸罩挂头上。别全用通用星星。
- 年代标注：80 = 80 后童年/青春记忆，90 = 90 后，00 = 00 后。

## 变更（审查 1）

2026-09-29 对抗审查。美术**已开工的 B5、G4 没换人**，只有 G4 的攻击少了一项。标「新（审查 1 换）」的是换了人的，旧的定妆图不要再出。

口径（后面几轮沿用）：
- **成年**：新角色的原型，官方年龄必须 ≥18；原型是真人剧的，以成年演员的形象为准。已有资产里用户亲自点过名的（B12 路飞、B21 樱木、G3 水手少女）保留，但要按成年体型出图。
- **年代**：看首播或流行时哪一代人正处在童年 / 青春期。长年重播、靠表情包流传的，保留原标。

### 换人（原型是小孩，或认不出）
- **B14 橙衣忍者（鸣人）→ 方块头矿工（我的世界史蒂夫式）**：鸣人的橙衣形象是 12 岁，属于小孩原型。换成 00 后人人认识的方块头；泥土方块是很好的 3D 转 2D 道具，命中碎成像素块，一眼能看出是什么。
