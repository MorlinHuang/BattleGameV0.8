# 《查手机》角色设定 —— 后续生图的形象基准

设定稿：`/workspace/art/chashouji/refsheet/turnaround_sheet.png`（男女主各一排，正/侧/背）
单张：`girl_turnaround.png` · `boy_turnaround.png`（另有 `_alt` 备选各一张）

三视图本身也是**用 `v13/raw/f050.png` 裁出来的单人图做 image-to-image 生出来的** ——
凭文字描述重画必然换一个人，这条在关键帧阶段已经验证过（见 chashouji-art skill）。
往后出任何新图（新姿态、新分镜、宣传图、表情差分），都拿这张设定稿当参考图。

## 女主（查岗党 —— 要看手机的那个）

七头身成年年轻女性，不是少女、不是萌系。及腰黑色长直发，发梢有层次，**右鬓角一朵红色小花发夹**。
浅粉长袖睡衣两件套：开襟翻领、正面一排红色小圆纽扣、领口袖口裤脚深粉滚边、
布料上均匀印白色卡通兔子头（小而稀疏规整）、同色长睡裤。白色毛绒兔子拖鞋，鞋头有兔耳兔脸。

## 男主（灭迹党 —— 藏手机的那个）

七头身成年年轻男性，肩宽、四肢修长，不是少年、不是萌系。黑色蓬松短发，发梢乱翘成刺猬状。
白色圆领短袖 T 恤，**胸口右侧一个小黑色卡通猫头**（只有正面有，侧面背面是干净纯白）。
黑色运动长裤，裤腿外侧各一条白色竖条纹从腰到裤脚。黑色拖鞋，鞋面印白猫脸（耳朵、眼睛、胡须）。

猫（男方）与兔（女方）是这两个人身上贯穿的符号，出新道具、新服装时沿用这一对。

## 画风与背景（每次 prompt 都要带上）

- 纯 2D 扁平卡通赛璐璐，粗黑描边，大色块平涂，阴影只用一层硬边色块
- 禁止渐变 / 噪点 / 细碎纹理 / 3D 立体质感 / 厚涂写实
- 背景纯品红实底 `#FF00FF`，不要透明背景、不要棋盘格、不要地板墙面、不要投影
- 画面里不要任何文字、标注、箭头、标尺线、水印（中文渲染是模型的稳定短板，一律程序绘制）

## 已知偏差

三视图里的脸比关键帧序列**写实一点**（眼睛小些、脸长些），头身比也略高。
拿它当参考图生新图时，服装、配色、符号能锁住，**脸型仍需要再拿一张关键帧一起喂**才稳。
