# 哥们出手交接表（美术 → 引擎，精美1 物理一致性）

对照 `docs/美术打磨自检.md` 第 4 节（4.4「需美术补帧」名单、4.6 引擎统一做法）。美术按所需角度重画出手帧，这里给引擎**出口点**和**出口方向 dir**。

- **坐标**：出口点是该人图集的**格内输出像素**（和 `trio_buddy.js` 里 `atk.hold` 同一坐标系，图集 json 的 anchor 一起列出，换屏幕坐标 = at + (点 − anchor) × s）。
- **角度**：屏幕角，0° = 水平向右，180° = 水平向左，正 = 往上（格内 y 向下，所以 θ = atan2(−(y₁ − y₀), x₁ − x₀)）。
- **投掷实物**（4.6 第 1 条）：dir = 出手前一帧握点 → 出手帧握点的方向（引擎按它反解初速、受重力落到目标）。这一列已经写进 `atk.hold`（出手前一帧、出手帧各一个点），引擎可以直接从 hold 算，也可以读这张表的数。
- **光束 / 拳 / 伸长肢体**（4.6 第 7 条）：dir = 出手帧肩 → 手（拳面 / 掌心）的指向；光束 / 拳影从出口点沿 dir 直线出去，不拐弯。
- 量法：子任务在 `preview/<名>_p6d.png` 上标点量（± 3 px，角度 ± 2°），对比图上画了 P → R 箭头和肩 → 手连线。
