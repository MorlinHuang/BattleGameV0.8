## 一、每个人必须有的东西（验收底线）

| 段 | 要求 | 样板怎么做的 |
|---|---|---|
| **进场** | 不能是一张图平移进来。要有**姿态变化**：进场里、**人已经露面之后**，至少切一次帧（画外切的不算） | 樱木：腾空扑（dive）→ 砸地（flop，落地压扁）→ 贴地滑（slide）→ 待机。格格：露面时收腿俯冲（tuck）→ 0.6 秒荡到最低点伸腿（kick）→ 抬手蓄力（`改_gege_enter_fine.json`）。B5：四帧走路循环 + 一步一伏 → 站定摆架（idle） |
| **待机** | 呼吸 + 至少一处**次级摆动**（头发、流苏、衣摆、脚、挂件），而且要**在胶片上量得出来**：次级摆动 ≥ 3 px，一次待机里至少完成一口呼吸 | 樱木：背一起一伏（头部峰峰 4.5 px，0.9 次/秒；原来 0.5 次/秒时 ≤ 0.45 px）+ 两只脚懒洋洋翘 + 手里篮球慢慢转；格格：呼吸 + 帽后流苏挂件自己晃（秋千不摆时流苏尖相对挂点峰峰 3.5 px，连同呼吸尖的屏幕位置峰峰 6.8 px）、跟着秋千往后拖 + 秋千本身在摆；B5：站立呼吸（头部峰峰 6.1 px，0.8 次/秒） |
| **出手** | **蓄力 → 出手（东西在这一帧离手）→ 收势 → 回待机**，至少 3 帧（蓄力 / 出手 / 收势） | 樱木：wind 0.28s → throw 0.1s（球离手）→ follow 0.26s；格格：raise 0.12 → wind 0.24 → throw 0.1（绣球离手）→ follow 0.3 |
| **道具** | 手里空着画，道具由运行时画在 hold 点；出完手手里重新"冒"一个 | 樱木的篮球是 3D 转盘图集；格格的绣球是平面图 |
| **锚点漂移** | 逐帧 ≤ 2px（量法见第八节） | 改完重量：樱木 1.37px、格格 1.09px、B5 1.47px（`shots/trio_std/漂移实测.txt` 文末「第二轮」） |
| **一致性** | 帧与帧之间人一样大（头的缩放 0.97~1.03）、服装细节一致 | frames.py 残差表最后一列"头"（不是前面搜索那一段的"头缩放"） |

帧与帧之间**硬切**，不做交叉淡化（两张不同姿态叠在一起是两副骨架互相穿透的重影，记忆 chashouji-keyframe-frames 第 8 条）。
硬切不读成卡顿，靠三件事：① 不动的部位严格对齐（下面的配准）；② 换帧落在动作的"节拍点"上（出手那一下、荡到两头停住的那一刻）；
③ 切的那一下配整体的挤压 / 前后甩（引擎做，数据里填幅度）。

## 二、路线：为什么是"动作条帧 + 程序补次级动作"（混合，c）

三条路都试了，证据在 `shots/trio_std/`：

| 路线 | 试的结果 | 结论 |
|---|---|---|
| (b) 切件：把立绘切成大臂小臂转 | `路线对比_切件vs生图.png`：樱木 idle 的小臂绕肘一转，身后露出从没画过的胸口（缺口）；想做"举过头"的蓄力，上臂在原图里根本不存在。记忆 baijia-fx-cutout-rig：被遮住的部位要合成补；查手机 v10~v12 网格变形被用户否掉（"spine 效果还是太差"） | 只能做小幅摆动，做不了蓄力 / 出手这种大姿态 |
| (a) 纯动作条帧 | 同一张图里的 4 个姿势，人的大小基本一致（头缩放 0.96~1.06）；配准后不动部位残差 ≤ 1.71px。**但**模型会把"不动的部位"本身画走样：樱木出手那格腿短了一截，短裤对齐了、鞋还差 20px | 大姿态靠它；必须配准 + 自检 + 移植修补；只靠帧的话待机是死的（一张图） |
| **(c) 混合（采用）** | 关键姿势用动作条帧；呼吸（绕锚点胀缩）、次级摆动（flex 条带错位）、挂件层（parts）、秋千摆、落地压扁、出手前后甩由引擎程序做 | 大动作有画面质量、小动作连续不停；胶片见第八节 |

## 三、流程总览

```
定妆图（美术已在做，buddy/ref/B*.png）
  → ① 动作条生图（第四节提示词，定妆图当参考图，一张图 4 个姿势，绿幕 / 品红幕）
  → ② frames.py cells：切格、出预览，量 head / fixed / anchor 三个框填 frames.json
  → ③ frames.py build：抠像 → 按头统一缩放 → 按不动部位配准 → 图集 web/assets/trio/<编号_名>.webp；看残差和 check
  → ④ 有走样就 graft 移植；看 preview 三张图（frames / onion / yellow）
  → ⑤ 量 hold / 挂绳点 / flex 框（preview/<名>_frames.png 上量，就是 cfg 坐标）
  → ⑥ 在 trio_buddy.js / trio_bestie.js 的 cast 里加这个人（第六节字段）
  → ⑦ 道具：3D 转盘（第七节）或平面图；挂件层用 part.py
  → ⑧ 部署、拍胶片、量漂移（第八节），过自检清单
```

### 目录与命名

- 角色目录：`v14/trio/buddy/<编号>_<拼音或英文名>/`（闺蜜在 `bestie/`），里面 `raw/`（动作条原图）+ `frames.json`。样板在 `tools/samples/` 下，结构一样。
- 图集：`web/assets/trio/<编号>_<名>.webp` + `.json`（frames.py 自动出，名字 = 目录名）

  `idle` 待机 / `wind` 蓄力 / `raise` 抬手（蓄力前段）/ `throw` 出手 / `follow` 收势 /

## 四、生图：定妆 → 动作条

### 4.1 提示词模板（照抄，替换【】）

**要点**（每一条都是踩出来的）：
- **一张图出 4 个姿势**（地板趴着的人：竖图 `1024x1536` 4 行；坐 / 站 / 挂着的人：竖图 2x2）。同一张图里的人大小、服装最一致；分开生图人会漂。
- **参考图**：定妆图 + 已经出好的同一个人的动作条（第二张动作条带上第一张，最后一格再画一遍 idle 当对齐锚）。
- **写死"不动的部位"**：趴着的写"hips and legs in exactly the same place in every row"，秋千写"board in the same place"。模型不一定听，但能少走样。
- 手里**空着**（EMPTY hands），写"as if holding a ball"让手型对。道具运行时画。
- 引擎画的东西（秋千绳、座板）**不要画**，或者画了用 frames.json 的 `erase` 抠掉（格格就是这样）。绳子写"ROPES ARE NOT DRAWN"。
- 幕布：纯品红 `#FF00FF`；**粉 / 紫 / 红粉系角色用绿幕 `#00FF00`**。生图有时直接回透明底，工具自动识别，别铺回幕布再抠。
- 提示词里**不写作品名、角色名**（借梗不写原名）；**"bikini" + 跪姿 会被拒**，写"crop top and matching briefs"一类描述。
- 朝向：哥们朝左（facing LEFT），闺蜜朝右（facing RIGHT）。
- **定妆时已经拆成几层的人**（B18 扇子、G5 算盘、G13 绳子、G18 翎子和靠旗、G29 竹棒），参考图**只用人那一层 `ref/<编号>_body.png`**，提示词写明 "NO folding fan / NO back flags / NO feathers / NO abacus / NO bamboo staff / NO rope drawn"。这几件东西由挂件层画（6.6 节）；动作条里画了，就会和挂件层叠成两份。

### 4.2 生图自检（出图就看，不行当场重生）

- 4 格里人一样大、衣服细节一样（花纹、扣子、鞋）；不动的部位位置差不多。
- 蓄力和出手的**幅度要大**：缩到游戏尺寸（樱木 ~450px 宽、格格 ~330px 高）还能一眼看出是在"拉"和"甩"。
- 格与格之间留空（工具按连通块切，粘在一起切不开；小的脱开的碎块如流苏会自动并回最近的人）。

### 4.3 后排地面和前排地面（地板）的区别

| | 前排地板（B21~B30、G21~G30） | 后排地面（B5~B10、G4~G10） |
|---|---|---|
| 站位 | 两个下角、主角脚以下的地板上，**画在主角之前**（`depth` 1.3） | **自己主角身后**的地板上（哥们在男生身后右边、闺蜜在女生身后左边），**画在主角之后**（`depth` 0.8） |
| 遮挡 | 挡主角的脚 / 腿，所以只能趴 / 跪 / 坐，贴着下沿 | 被主角挡：主角的腿、胳膊会盖住他一部分（B5 的前脚常被男生的小腿挡住）。**出手的东西、特效画在主角之上**（drawOver），不会被挡 |
| 大小 | 近，大：樱木剪影约 2.65 万屏幕像素 | 远，小：按透视比主角小一圈。**`at.s` 让站姿高度 ≈ 主角身高 × 0.75**（B5 482 × 0.85 ≈ 410 px）；脚底 `at.y` = 1195 − 350 × (1 − 0.9) ≈ 1158（同 crew.js 后排：抬高 = (地面 − 视平线) × (1 − 远近)） |
| 横向 | 樱木锚点 x 712 | 在自己主角身后、别整个藏住：哥们 x 780~820、闺蜜 x 140~180；**整个人别出画**（最宽的出手帧也要在 0~960 内） |
| 最低点 | y ≤ 1334（下面是评论区） | 脚底在 1158 左右，不碰评论区 |
| 生图 | 模板 A（趴 / 跪，4 行） | 模板 C（站，2x2 两张：出手条 + 走路条） |
| 配准 | fixed = 贴地的肚皮 / 大腿 | fixed = **只框承重的那只脚**（两只脚一起框，模型把两脚间距画得不一样时，一个框对不齐两只脚，B5 第一版残差 5 px）；走路帧写进 `loose` |
| 前后倾 | `leanK` 0（趴着） | `leanK` 0：站着的人绕脚底整体一倾，另一只脚就被挪走几 px（B5 量出来 4 px），蓄力、出手的幅度全画在帧上 |

**和 crew.js 的关系**：后排地面原来的 7 个人（B1 冲浪男、B2 金箍浪子、B3 贝勒、B4 八神、G1 墨镜短发、G2 蓝发发明家、G3 月光水手）是 crew.js 的
**滑板 / 平衡车旋转层立绘**：一张立绘切成 arm / body / lo 几层，身体绕腰转着瞄准、喷水 / 喷雾是粒子流（crew.js 头注释）。它们在 `trio_buddy.js` / `trio_bestie.js`
的 `ground` 表里（编号 → crew.js 的形象下标），三人组照旧调 crew.js 出它们，**这次没动**。新做的后排地面人（B5~B10、G4~G10）走本规范，是 trio.js 的帧序列 Act，放进 `cast`，
跟 crew.js 没有关系。两套并存：`Trio()` 召一组时，组里的 ground 编号在 `ground` 表里就交给 crew.js，在 `cast` 里就交给 trio.js。
**以后怎么迁移**（B1~B4、G1~G3 要换成帧序列时）：① 按模板 C 出条 1（滑板 / 平衡车上站着：待机、蓄力举枪、喷、收势）+ 条 2（进场：`ride` 写法，帧里画上滑板 / 平衡车）；
② 出手用 `spray`（水枪 / 喷雾：雾团按 `spray.color` 画，想要现在 crew.js 那种水柱，就先把 `spray.rate` 提高到 90 以上再看，不够再找引擎负责人加水柱画法）；
③ 在 `cast` 里加上这个编号，**同时从 `ground` 表删掉它**（两边都有时 `ground` 优先，新做的不会出来）；④ 按第八节拍胶片，和旧版并排对比，过了再删 crew.js 里那一套形象。

## 五、切帧 / 对齐 / 打图集

### 5.1 命令（在 `v14/trio` 下）

```bash
python3 tools/frames.py buddy/B25_coach cells    # 切格 → preview/B25_coach_cells.png（原图像素 + 50px 格线）
# 在 cells 预览上量三个框，写进 buddy/B25_coach/frames.json（格式见 frames.py 文件头）

python3 tools/part.py buddy/ref/B18_fan.png B18_fan w 120   # 挂件层（可选）
```

### 5.2 frames.json 要量的三个框（在参考帧 idle 上，cells 预览的像素）

| 字段 | 量什么 | 樱木 | 格格 |
|---|---|---|---|
| `head` | 头（含发型 / 帽子，不含手）：**缩放按头对齐** | [65,5,195,118] | [85,15,265,180] |
| `fixed` | 这个动作里**本来就不该动**的部位：**平移按它对齐**。要有形状轮廓，别只框一块平行条纹的布 | 短裤 + 大腿 [350,155,720,295] | 臀 + 胯 [95,330,290,440]（座板每格画得不一样，不能用） |
| `anchor` | 锚点：跟地面 / 座板 / 墙接触的那一点，引擎把它钉在 `at` 上，呼吸也绕它 | 肚皮贴地 [450,295] | 座板中心 [205,455] |

站着的人（后排地面）：`fixed` **只框承重的那只脚**（B5 前脚 `[50,600,250,700]`），另一只脚会随出手迈出去（B5 hitA 后脚往前 15 px，是动作不是走样）；
走路、跑、跳这种脚在动的帧写进 `"loose": ["walk1", ...]`：横向按头对齐、竖向按脚底贴参考帧的地面线，残差表里不计。

可选：`lift`（挂着的东西碰到身体、画不出三边透明的 flex 框时，把它从每一帧里拆出来做挂件层，帧里原位置自动补画；格格帽后流苏，见 6.3 节）、
`erase`（按 HSV 抠掉引擎自己画的东西，格格的座板）、`check`（另外量几个本该不动的部位，**输出像素**）、
`graft`（从好的一帧把走样的那块搬过来，**输出像素**，左边 `feather` 宽渐变，渐变带放在两帧本来就对齐的地方）。**渐变带不能压在衣服边、裤脚、袖口这类有轮廓线的地方**：两帧的轮廓线没对齐，渐变一混就是一道半透明重影（樱木 throw 的裤脚就是这样，见 `shots/trio_std/审_樱木throw裤脚移植缝.png`）。把渐变带放在光皮肤或大块纯色布料上，移植完在 `_yellow.png` 上把那一格放大 3 倍看渐变带。

### 5.3 build 的输出怎么读

```
配准残差（输出像素）：  wind dx +0.01 dy -0.16 ...   最大残差 1.71px（验收 ≤ 2）
  鞋：idle +0.0,+0.0  wind +0.0,-1.5  throw +0.0,-1.5  follow +0.0,+0.0  dive -5.6,-14.6 ...

```
- **在场的帧**（idle / 出手那几帧）残差和 check 都要 ≤ 2；进场帧（dive / flop / slide）本来就在动，不算。
- 某一帧 check 偏得多（樱木 throw 的鞋 −20）= 模型把这块画走样了 → 用 `graft` 从相邻的好帧移植，再 build 一遍确认归零。
- 头的比例看**残差表最后一列"头"**，应在 0.97~1.03。前面那段"头缩放 1.06（匹配 0.89）"是搜索时的倍数，不用管它。
- "不动部位匹配"低于 0.8 的在场帧（格格 raise 0.71、throw 0.64），配准可能被别的形状拐走，一定要看 onion 图确认不动的部位是一个清楚的影子。
- build 一次约 3 分钟（两个样板实测），前台等它跑完，别以为卡住了。
- 剪影面积（对齐同槽位的大小用）：
  `python3 -c "import numpy as np;from PIL import Image;a=np.array(Image.open('../../web/assets/trio/<名>.webp').convert('RGBA'))[:<cellH>,:<cellW>,3];print((a>128).sum()*<s>**2)"`
  （取第一格也就是参考帧，s 是 at 的第三项）

### 6.2 进场 / 离场

`enter` 写成对象 `{ kind, seq, ... }`（旧的单张立绘写字符串）。**通用字段**：

| 字段 | 说明 |
|---|---|
| `enter.kind` | 进场写法，见下表（12 种，名单上每个人对应哪一种见第九节） |
| `enter.seq` | `[[帧, 秒, 'land'?], ...]`：进场里按时间换帧，最后一段写个大数（9）表示一直持续到进场结束。**帧可以写成数组** `[['walk1','walk2','walk3','walk2'], 9]` = 这一段按 `enter.fps` 循环（走路、跑、骑车蹬腿）。标 `'land'` 的那一帧切进来时整个人压扁一下（`enter.sq`，0.12）。**所有 kind 都能写 seq，秋千也能**（格格） |

| kind | 用在 | 专有字段 | 例 / 测通胶片 |

| `dive` | 腾空扑地再滑 | `h` 腾空多高 px、`air` 几秒落地、`sq` | 樱木 `改_sak_*` |
| `slide` / `dash` / `roll` / `crawl` / `creep` / `spring` | 扑地滑 / 斜冲 / 翻滚 / 扒墙爬 / 匍匐 / 弹 | 无（路线写死在引擎） | 旧的 6 人 `r_*_crop.jpg` |
| `swing` | 秋千 | `swing`（见下）+ `ropes` | 格格 `改_gege_enter*` |

| **`fly`** | 从上面飞下 / 飘下：御剑、酒坛、月亮、无人机、船头滑出 | `from: [dx, dy]` 起点相对锚点的屏幕偏移（默认 `[±0.6 × 画外, −720]`，从自己那侧上方）、`air` 几秒到位、`tilt` 飞的时候斜着多少 | `测_fly_spray`（T4） |

| **`drop`** | 倒挂垂下：顺着一根丝 / 绳从上面掉下来、冲过头再弹回（蹦极），在场绕绳顶轻轻荡 | `len` 从多高掉下来（默认 700）、`line` 丝系在贴图上哪一点、`sway` 荡多少 rad（默认 0.04）、`w / fill / edge` 丝的粗细颜色；**`pivot` 填绳顶**（在贴图外，锚点往上 700 左右，同秋千） | `测_drop_slash`（T5） |
| **`appear`** | 原地出现：闪现、凭空浮现、变身闪光、圣衣拼身、阴影一闪、九尾托着出现；钻出、坐上墙头 | `fx: 'flash' / 'smoke'` 闪光（亮光 + 八道光芒）/ 烟团往外散、`color` 光或烟的颜色、`fade` 几秒淡入（默认 0.35）；不写 `rise` = 淡入 + 由小弹大；**写 `rise: <px>`** = 从一条线后面升上来（线默认在人的最低点，`cut` 改成贴图里别的高度，比如墙头那一行），离场反过来 | 闪光 `测_appear_punch`（T2）；升起 + 烟 `测_rise_ribbon`（T6） |
| **`rope`** | 横绳：一根两头系住的绳，人躺 / 坐在绳上从自己那侧滑进来，在场随绳颠、来回荡 | `ends: [[x, y], [x, y]]` 绳两头（**屏幕像素**，可以在画外）、`touch` 人压在绳上的那一点（贴图像素）、`sag` 坠多少、`sway` 荡几 px、`w / fill / edge`。绳子引擎画、画在人之下 | `测_rope_tether_net`（T7） |

秋千 `swing`：`a0` 进场摆幅、`a` 在场摆幅（rad）、`tau` 收敛快慢、`w` 角频率；`pump: { fwd, back, min }` 在场时往前荡用 fwd 帧、往后荡用 back 帧，摆幅小于 min 不蹬。
**进场的姿态用 enter.seq 写**，别指望 pump：摆幅降到 min 的时刻 = tau × ln((a0 − a) / (min − a))（格格 0.87 秒）比第一次往后荡（π / w = 1.21 秒）早，pump 在进场里只会出 fwd 帧。
格格：`enter: { kind: 'swing', seq: [['tuck', 0.6], ['kick', 9]] }` —— 0.6 秒正好是摆角 A0·cos(wt) 过零（荡到最低点），在节拍点上换帧。

### 6.3 待机 / 次级动作

| 字段 | 说明 |
|---|---|
| `idle` | `{ frame, breathe: [幅度, 每秒几次, 横向补偿] }`。呼吸 = 绕锚点竖向胀缩（0.014~0.022），横向反着补一点保体积（默认 0.4，**趴着的给 0**，不然贴地的脚左右挪） |
| `flex` | `{ 帧: [[x0, y0, x1, y1, 钉住边, 幅度px, 每秒几次, 跟摆], ...] }`：挂着的东西（流苏、发梢、脚、衣摆）按条带错位晃。钉住边 `'t'` 顶（流苏、头发）/ `'l'` 左（脚：小腿钉住、脚尖翘）。**框除了钉住的那一边，其余三边必须是透明的**，不然错位会把身体撕开。跟摆（秋千）= 摆的角速度 × 这个数，流苏往后拖。只给待着时间长的帧写（idle、秋千的 kick/tuck），出手帧一闪而过不用写。**框量完必须跑 8.4 节的"flex 框三边透明"检查**：格格三个框都压到了肩膀或头发，流苏一甩就把肩膀撕开一个口（`shots/trio_std/审_格格流苏跟摆与肩膀撕口.png`）。**挂着的东西下端或侧边碰到身体的**（流苏贴着肩膀、辫梢压在背上），画不出三边透明的框，不能用 flex，要拆成挂件层（`parts` + `sway`），并在人那一层把它原来的位置补画出来 |
| `parts` | 挂件层（扇子、靠旗、翎子、披风、流苏这类**单独拆出来的一层**）：`[{ src, pivot, z, at: { 帧: [x, y, 角度] }, sway: [幅度 rad, 每秒几次, 跟摆] }]`。pivot 是挂件图上挂住的点（part.py 的 grid 上量）；z −1 画在人后、1 人前；**at 里没写的帧就不画**（出手那帧要把扇子拿下来就不写那一帧）。跟摆 = 秋千 / 荡的角速度（rad/s）× 这个数，挂件往**反方向**拖（rad，不是 px：格格 0.25，秋千最猛时拖 ~0.8 rad）。幅度按"秋千不摆时尖上也 ≥ 3 px"定：幅度 rad × 挂件长 ≥ 3 |
| **拆挂件（lift）** | 帧里已经画着、下端碰到身体的挂件（格格流苏）：frames.json 加 `"lift": [{ "name": "G11_tassel", "from": "idle", "box": { 帧: [x0,y0,x1,y1] }, "hsv": [[[h0,h1],[s0,s1],[v0,v1]], ...] }]`（框是输出像素，每帧框住它、别框进身上同色的地方；hsv 写它的几种颜色，描边自动带上）。build 时从每帧拆出来、原位置从四周往里补（背景那侧补透明、贴着头发 / 肩膀那侧顺着补），挂件图出到 `web/assets/trio/<name>.webp`，并打印 `parts` 那一条（pivot、每帧的 at）直接贴。格格：`tools/samples/G11_gege/frames.json`，放大对比 `shots/trio_std/改_格格流苏挂件与肩膀_x3.png` |
| `ropes` | 秋千（引擎画绳和座板）：`ends` 座板两头、`board` 座板框、`grip: { 帧: [左手点, 右手点] }` 这一帧哪只手握着绳（绳子先拐到手上再往上，手盖住绳 = 握住）、`flowers` 绳上小花颜色、`wood` 座板三色 |
