# 档 3 三人组角色规范（帧动画标准，2026-09-30）

给美术照着出一个完整的人：从定妆图到在游戏里动起来、拍胶片自检。**样板两个**：B21 樱木（地板，扑地 + 趴着甩 3D 篮球）、
G11 格格（上方，秋千 + 荡到最前面抛绣球）。所有文件、命令、数字都能在样板里找到原件，拿不准就照样板抄。

- 名单与 10 组搭配：`docs/三人组30人名单.md`；方案背景：`docs/帮手三人组.md`
- 引擎（不用改）：`web/trio.js`；**你要填的数据**：`web/trio_buddy.js`（哥们）/ `web/trio_bestie.js`（闺蜜）
- 工具：`v14/trio/tools/`（frames.py 切帧配准打图集、part.py 挂件层、drift.py 量漂移、film.py 拍胶片）
- 样板素材：`v14/trio/tools/samples/B21_sakura/`、`v14/trio/tools/samples/G11_gege/`（raw 原图 + frames.json）

## 一、每个人必须有的东西（验收底线）

| 段 | 要求 | 样板怎么做的 |
|---|---|---|
| **进场** | 不能是一张图平移进来。要有**姿态变化**：至少 2 帧进场帧，或者边进边按动作换帧 | 樱木：腾空扑（dive）→ 砸地（flop，落地压扁）→ 贴地滑（slide）→ 待机；格格：荡进来的一路往前荡伸腿（kick）、往后荡收腿（tuck） |
| **待机** | 呼吸 + 至少一处**次级摆动**（头发、流苏、衣摆、脚、挂件） | 樱木：背一起一伏 + 两只脚懒洋洋翘 + 手里篮球慢慢转；格格：呼吸 + 帽后流苏跟着秋千甩 + 秋千本身在摆 |
| **出手** | **蓄力 → 出手（东西在这一帧离手）→ 收势 → 回待机**，至少 3 帧（蓄力 / 出手 / 收势） | 樱木：wind 0.28s → throw 0.1s（球离手）→ follow 0.26s；格格：raise 0.12 → wind 0.24 → throw 0.1（绣球离手）→ follow 0.3 |
| **道具** | 手里空着画，道具由运行时画在 hold 点；出完手手里重新"冒"一个 | 樱木的篮球是 3D 转盘图集；格格的绣球是平面图 |
| **锚点漂移** | 逐帧 ≤ 2px（量法见第八节） | 樱木在场各帧最大 0.79px、格格 1.07px（`shots/trio_std/漂移实测.txt`） |
| **一致性** | 帧与帧之间人一样大（头的缩放 0.97~1.03）、服装细节一致 | frames.py 打印每帧"头"的比例 |

帧与帧之间**硬切**，不做交叉淡化（两张不同姿态叠在一起是两副骨架互相穿透的重影，记忆 chashouji-keyframe-frames 第 8 条）。
硬切不读成卡顿，靠三件事：① 不动的部位严格对齐（下面的配准）；② 换帧落在动作的"节拍点"上（出手那一下、荡到两头停住的那一刻）；
③ 切的那一下配整体的挤压 / 前后甩（引擎做，数据里填幅度）。

## 二、路线：为什么是"动作条帧 + 程序补次级动作"（混合，c）

三条路都试了，证据在 `shots/trio_std/`：

| 路线 | 试的结果 | 结论 |
|---|---|---|
| (b) 切件：把立绘切成大臂小臂转 | `路线对比_切件vs生图.png`：樱木 idle 的小臂绕肘一转，身后露出从没画过的胸口（缺口）；想做"举过头"的蓄力，上臂在原图里根本不存在。记忆 baijia-fx-cutout-rig：被遮住的部位要合成补；查手机 v10~v12 网格变形被用户否掉（"spine 效果还是太差"） | 只能做小幅摆动，做不了蓄力 / 出手这种大姿态 |
| (a) 纯动作条帧 | 同一张图里的 4 个姿势，人的大小基本一致（头缩放 0.96~1.06）；配准后不动部位残差 ≤ 1.71px。**但**模型会把"不动的部位"本身画走样：樱木出手那格腿短了一截，短裤对齐了、鞋还差 20px | 大姿态靠它；必须配准 + 自检 + 移植修补；只靠帧的话待机是死的（一张图） |
| **(c) 混合（采用）** | 关键姿势用动作条帧；呼吸（绕锚点胀缩）、次级摆动（flex 条带错位）、挂件层（parts）、秋千摆、落地压扁、出手前后甩由引擎程序做 | 大动作有画面质量、小动作连续不停；胶片见第八节 |

## 三、流程总览

```
定妆图（美术已在做，buddy/ref/B*.png）
  → ① 动作条生图（第四节提示词，定妆图当参考图，一张图 4 个姿势，绿幕 / 品红幕）
  → ② frames.py cells：切格、出预览，量 head / fixed / anchor 三个框填 frames.json
  → ③ frames.py build：抠像 → 按头统一缩放 → 按不动部位配准 → 图集 web/assets/trio/<编号_名>.webp；看残差和 check
  → ④ 有走样就 graft 移植；看 preview 三张图（frames / onion / yellow）
  → ⑤ 量 hold / 挂绳点 / flex 框（preview/<名>_frames.png 上量，就是 cfg 坐标）
  → ⑥ 在 trio_buddy.js / trio_bestie.js 的 cast 里加这个人（第六节字段）
  → ⑦ 道具：3D 转盘（第七节）或平面图；挂件层用 part.py
  → ⑧ 部署、拍胶片、量漂移（第八节），过自检清单
```

### 目录与命名

- 角色目录：`v14/trio/buddy/<编号>_<拼音或英文名>/`（闺蜜在 `bestie/`），里面 `raw/`（动作条原图）+ `frames.json`。样板在 `tools/samples/` 下，结构一样。
- 图集：`web/assets/trio/<编号>_<名>.webp` + `.json`（frames.py 自动出，名字 = 目录名）
- 挂件：`web/assets/trio/<编号>_<挂件名>.webp`（part.py）
- 3D 道具：`web/assets/trio/prop_<英文名>.webp`（pack_atlas.py）；建模脚本 `tools/3d/<英文名>.py`
- 帧名：小写英文，固定用这些词（引擎不认名字，是给人读的；同一种动作全员同名，方便横比）：
  `idle` 待机 / `wind` 蓄力 / `raise` 抬手（蓄力前段）/ `throw` 出手 / `follow` 收势 /
  进场：`dive` 腾空 `flop` 砸地 `slide` 滑行 `roll` 翻滚 `land` 落地 `crawl1/crawl2` 爬 / 秋千：`kick` 伸腿 `tuck` 收腿

## 四、生图：定妆 → 动作条

### 4.1 提示词模板（照抄，替换【】）

**要点**（每一条都是踩出来的）：
- **一张图出 4 个姿势**（地板趴着的人：竖图 `1024x1536` 4 行；坐 / 站 / 挂着的人：竖图 2x2）。同一张图里的人大小、服装最一致；分开生图人会漂。
- **参考图**：定妆图 + 已经出好的同一个人的动作条（第二张动作条带上第一张，最后一格再画一遍 idle 当对齐锚）。
- **写死"不动的部位"**：趴着的写"hips and legs in exactly the same place in every row"，秋千写"board in the same place"。模型不一定听，但能少走样。
- 手里**空着**（EMPTY hands），写"as if holding a ball"让手型对。道具运行时画。
- 引擎画的东西（秋千绳、座板）**不要画**，或者画了用 frames.json 的 `erase` 抠掉（格格就是这样）。绳子写"ROPES ARE NOT DRAWN"。
- 幕布：纯品红 `#FF00FF`；**粉 / 紫 / 红粉系角色用绿幕 `#00FF00`**。生图有时直接回透明底，工具自动识别，别铺回幕布再抠。
- 提示词里**不写作品名、角色名**（借梗不写原名）；**"bikini" + 跪姿 会被拒**，写"crop top and matching briefs"一类描述。
- 朝向：哥们朝左（facing LEFT），闺蜜朝右（facing RIGHT）。

**模板 A：地板（趴 / 半跪），竖图 4 行**

```
Character animation pose sheet, 4 rows stacked vertically, each row one full-body pose of THE SAME character as the reference image
(【发型、服装、配色、鞋，逐项写】), anime cel-shading, clean black lineart, identical character size, identical costume details and
identical camera distance in every row. In every row 【姿态总述：LIES ON HIS BELLY on the floor facing LEFT, legs stretched out to the right】,
【不动的部位：hips and legs in exactly the same place in every row (only arms, head and chest change)】. His hands are EMPTY (no 【道具】 drawn).
Row 1 (idle): 【待机姿势，手型 as if holding a 【道具】】.
Row 2 (wind-up): 【蓄力：手臂大幅往后拉，表情用力】.
Row 3 (release): 【出手：手臂甩到最前、手张开、身体前冲、喊】.
Row 4 (follow-through): 【收势：手臂顺势落下、身体回落、得意表情】.
Rows separated by generous empty space, no character overlaps another row, nothing cropped by the image border.
Background MUST be pure flat magenta #FF00FF single solid color, no gradient, no shadow, no floor line, no text, no panel borders.
```
进场条同样格式：Row 1~3 写进场的三个瞬间（如腾空扑 / 砸地 / 滑行），**Row 4 再画一遍 idle**（"exactly like row 1 of the reference sheet"）。
樱木原文见 `tools/samples/B21_sakura/` 的两张 raw 图（生成它们的提示词就是上面这个模板填的）。

**模板 B：上方（秋千 / 扒墙 / 悬浮），竖图 2x2**

```
Character animation pose sheet, 2x2 grid (4 poses), each pose one full-body drawing of THE SAME 【young woman / man】 as the reference image
(【外观逐项】), anime cel-shading, clean black lineart, identical character size, identical costume details and identical camera distance in all
four poses. In every pose 【姿态总述：she SITS SIDEWAYS on the same plain wooden swing seat board, facing RIGHT; the board is in exactly the same
place and size in every cell】. 【引擎画的东西：The swing ROPES ARE NOT DRAWN at all. Her LEFT hand always grips in the air at shoulder height
directly above the LEFT end of the board, as if holding a rope.】 Her right hand is empty.
Top-left (idle): ... Top-right (wind-up): ... Bottom-left (release): ... Bottom-right (follow-through): ...
Generous empty space between cells, nothing overlaps another cell, nothing cropped.
Background MUST be pure flat chroma green #00FF00 single solid color, no gradient, no shadow, no ground, no text, no panel borders.
```
秋千的第二张：强化蓄力（手臂甩到身后、远离脸）+ 往后荡收腿（tuck）+ 往前荡伸腿（kick）+ idle。
**第一张蓄力往往不够大**（格格第一张的 wind 只是举手）——不够就在第二张里单独要一个 "strong wind-up"，弱的那张留作 `raise`（蓄力前段）正好多一帧。

### 4.2 生图自检（出图就看，不行当场重生）

- 4 格里人一样大、衣服细节一样（花纹、扣子、鞋）；不动的部位位置差不多。
- 蓄力和出手的**幅度要大**：缩到游戏尺寸（樱木 ~450px 宽、格格 ~330px 高）还能一眼看出是在"拉"和"甩"。
- 格与格之间留空（工具按连通块切，粘在一起切不开；小的脱开的碎块如流苏会自动并回最近的人）。

## 五、切帧 / 对齐 / 打图集

### 5.1 命令（在 `v14/trio` 下）

```bash
python3 tools/frames.py buddy/B25_coach cells    # 切格 → preview/B25_coach_cells.png（原图像素 + 50px 格线）
# 在 cells 预览上量三个框，写进 buddy/B25_coach/frames.json（格式见 frames.py 文件头）
python3 tools/frames.py buddy/B25_coach build    # 配准 + 出图集，打印残差 / check / cfg 片段
python3 tools/part.py buddy/ref/B18_fan.png B18_fan w 120   # 挂件层（可选）
```

### 5.2 frames.json 要量的三个框（在参考帧 idle 上，cells 预览的像素）

| 字段 | 量什么 | 樱木 | 格格 |
|---|---|---|---|
| `head` | 头（含发型 / 帽子，不含手）：**缩放按头对齐** | [65,5,195,118] | [85,15,265,180] |
| `fixed` | 这个动作里**本来就不该动**的部位：**平移按它对齐**。要有形状轮廓，别只框一块平行条纹的布 | 短裤 + 大腿 [350,155,720,295] | 臀 + 胯 [95,330,290,440]（座板每格画得不一样，不能用） |
| `anchor` | 锚点：跟地面 / 座板 / 墙接触的那一点，引擎把它钉在 `at` 上，呼吸也绕它 | 肚皮贴地 [450,295] | 座板中心 [205,455] |
| `size` | 参考帧剪影缩到多少屏幕像素 | ["w",470] | ["h",330] |

可选：`erase`（按 HSV 抠掉引擎自己画的东西，格格的座板）、`check`（另外量几个本该不动的部位，**输出像素**）、
`graft`（从好的一帧把走样的那块搬过来，**输出像素**，左边 `feather` 宽渐变，渐变带放在两帧本来就对齐的地方）。

### 5.3 build 的输出怎么读

```
配准残差（输出像素）：  wind dx +0.01 dy -0.16 ...   最大残差 1.71px（验收 ≤ 2）
  鞋：idle +0.0,+0.0  wind +0.0,-1.5  throw +0.0,-1.5  follow +0.0,+0.0  dive -5.6,-14.6 ...
cfg：frames: { src: 'assets/trio/B21_sakura.webp', cell: [555, 208], cols: 4, names: [...] }, anchor: [300.1, 199.2]
```
- **在场的帧**（idle / 出手那几帧）残差和 check 都要 ≤ 2；进场帧（dive / flop / slide）本来就在动，不算。
- 某一帧 check 偏得多（樱木 throw 的鞋 −20）= 模型把这块画走样了 → 用 `graft` 从相邻的好帧移植，再 build 一遍确认归零。
- 头的比例（最后一列）应在 0.97~1.03。

### 5.4 预览三张（`v14/trio/preview/`）

- `<名>_frames.png`：每帧一格、**输出像素**、50px 格线、放大 2 倍（格线 50 = 图上 100 显示像素）→ 在这上面量 hold / grip / flex / parts 的点，**就是 cfg 坐标**。
- `<名>_onion.png`：全部帧 35% 叠在一起，蓝框 = fixed，红圈 = 锚点。不动的部位应该是一个清楚的影子，糊成几层 = 没对齐。
- `<名>_yellow.png`：贴亮黄底看抠像（紫边 / 绿边 / 被抠穿的洞在黄底上最刺眼）。

### 5.5 贴图格式

- 图集：WebP q90，每帧一格、格子大小一样（= 全部帧并集），4 列；**所有帧锚点是同一个像素**（cfg 只填一个 anchor）。
- 贴图像素 × `at` 的 s = 屏幕像素（s 一般 1~1.05）。一个人一张图集约 160KB。
- 不用的帧（样板的 idle2）可以留在图集里当备用，不影响。

## 六、cfg 字段逐个说明（`trio_buddy.js` / `trio_bestie.js` 的 `cast`）

键是名单编号（`B21`）。**坐标：`at` 是 960×1334 版面的屏幕像素**（GROUND 1195 = 男女主脚底，1334 以下直播时被评论区盖住）；
**其余点都是图集一格里的像素**（`_frames.png` 上量）。

### 6.1 通用

| 字段 | 说明 | 樱木 / 格格 |
|---|---|---|
| `face` | +1 朝右（闺蜜，在左）/ −1 朝左（哥们，在右） | −1 / +1 |
| `sheet` | `{ src, cell, cols, names }`，frames.py 打印的原样贴 | |
| `anchor` | 锚点（frames.py 打印） | [300.1,199.2] / [128,212.3] |
| `at` | `[x, y, s]` 锚点落在屏幕哪、画多大。**槽位不能越界**：上方在侧边、男女主头顶以下；地板在两个下角、y ≤ 1334；后排地面在自己主角身后 | [712,1330,0.95] / [170,640,1] |
| `pivot` | 整体前后倾（和秋千摆）绕的点。秋千 = 绳顶（在画外，anchor.y − 740 左右） | [300,199] / [128,−530] |
| `leanK` | 整体前后倾打几折（0~1）。**趴着的人给 0**：绕肚皮转会把贴地的腿翘起来，读成一张图在转 | 0 / 0.5 |
| `depth` | 远近：< 1 画在主角身后（上方、后排），> 1 画在主角之前（地板） | 1.3 / 0.5 |
| `recipe` | 打中炸什么，main.js RECIPE 的键：thud feather star cream rouge debris petal water … bloom | thud / bloom |

### 6.2 进场 / 离场

| 字段 | 说明 |
|---|---|
| `enter` | 字符串（单张立绘的旧写法）或 `{ kind, seq, ... }`。kind：`dive` 腾空扑地再滑 / `slide` 扑地滑 / `dash` 斜冲 / `roll` 翻滚 / `crawl` 爬 / `creep` 匍匐 / `spring` 弹 / `swing` 荡（秋千写字符串 `'swing'`，帧由 `swing.pump` 管） |
| `enter.seq` | `[[帧, 秒, 'land'?], ...]`：进场 0.75 秒里按时间换帧，最后一段写个大数（9）表示一直持续到进场结束；标 `'land'` 的那一帧切进来时整个人压扁一下（`enter.sq` 幅度，0.12） |
| `enter.h / air` | dive：腾空多高（px）、腾空几秒（落地时间 = 砸地帧开始的时间） |
| `exit` | `{ frame }` 离场时用哪一帧（樱木 slide 倒滑出去，格格 tuck 荡出去） |
| `swing` | 秋千：`a0` 进场摆幅、`a` 在场摆幅（rad）、`tau` 收敛快慢、`w` 角频率；`pump: { fwd, back, min }` 往前荡用 fwd 帧、往后荡用 back 帧，摆幅小于 min 不蹬 |

### 6.3 待机 / 次级动作

| 字段 | 说明 |
|---|---|
| `idle` | `{ frame, breathe: [幅度, 每秒几次, 横向补偿] }`。呼吸 = 绕锚点竖向胀缩（0.014~0.022），横向反着补一点保体积（默认 0.4，**趴着的给 0**，不然贴地的脚左右挪） |
| `flex` | `{ 帧: [[x0, y0, x1, y1, 钉住边, 幅度px, 每秒几次, 跟摆], ...] }`：挂着的东西（流苏、发梢、脚、衣摆）按条带错位晃。钉住边 `'t'` 顶（流苏、头发）/ `'l'` 左（脚：小腿钉住、脚尖翘）。**框除了钉住的那一边，其余三边必须是透明的**，不然错位会把身体撕开。跟摆（秋千）= 摆的角速度 × 这个数，流苏往后拖。只给待着时间长的帧写（idle、秋千的 kick/tuck），出手帧一闪而过不用写 |
| `parts` | 挂件层（扇子、靠旗、翎子、披风这类**单独拆出来的一层**）：`[{ src, pivot, z, at: { 帧: [x, y, 角度] }, sway: [幅度 rad, 每秒几次, 跟摆] }]`。pivot 是挂件图上挂住的点（part.py 的 grid 上量）；z −1 画在人后、1 人前；**at 里没写的帧就不画**（出手那帧要把扇子拿下来就不写那一帧） |
| `ropes` | 秋千（引擎画绳和座板）：`ends` 座板两头、`board` 座板框、`grip: { 帧: [左手点, 右手点] }` 这一帧哪只手握着绳（绳子先拐到手上再往上，手盖住绳 = 握住）、`flowers` 绳上小花颜色、`wood` 座板三色 |

### 6.4 出手

| 字段 | 说明 |
|---|---|
| `atk.kind` | `throw` 丢东西 / `camera` 拍照闪光 / `beam` 发波（光线、气功、推掌）。`punch`（伸缩手臂）目前只支持单张立绘，帧序列要做伸缩类先找引擎负责人 |
| `atk.seq` | `[[帧, 秒, 'fire'?], ...]`：蓄力 → 出手（标 `'fire'`，**东西在这一帧开始的那一刻离手**）→ 收势。蓄力总时长 = 提前量：秋千的人会自动在"荡到最前面"那一刻出手。经验值：蓄力 0.25~0.36、出手 0.08~0.1（发波 = beam.fire）、收势 0.25~0.3 |
| `atk.hold` | `{ 帧: [x, y] }` 东西拿在哪；**出手帧那一格的点就是出手点**。没写的帧手里不画东西 |
| `atk.gap` | 两次出手之间歇几秒（秋千不用，按摆的周期） |
| `atk.item / prop / scale` | 平面道具：item 名 + 贴图 + 缩放（格格绣球 `trio_prop_ball.webp` × 0.5） |
| `atk.atlas / r` | 3D 转盘道具：`{ src, n: 36, cols: 6, cell, scale }`（pack_atlas.py 打印的原样填）、`r` 屏幕半径 |
| `atk.T / arc / spin` | 飞行秒数、弧高（× 距离）、转速 rad/s。**3D 转盘转速 = π / T（飞行途中转半圈）** |
| `atk.idleSpin` | 拿在手里时慢慢转（rad/s，篮球 1.6：手指拨着玩） |
| `atk.stretch` | 出手那一下整个人往出手方向拉长多少（0~0.05；趴着的给 0） |
| `atk.onHit` | 打中之后：`bounce` 弹开 / `heart` 冒爱心 / `lips` 口红印 / `wear` 挂在头上；`miss` 故意扔偏的比例 |
| `atk.beam` | 发波：`{ fire, drip, ball, glow, edge, layers }`（抄 B22 悟空的） |

### 6.5 组表

`groups` 已按名单填好 10 组。**你只要在 `cast` 里加人，他所在的组就自动亮起来**：组里还没做的人那个槽位空着，一整组都没做就不参与抽。

### 8.2 拍胶片（桌面容器里跑 `v14/trio/tools/film.py`，先 scp 到 `/tmp/film.py`）

```bash
ssh kf-deployment 'python3 /tmp/film.py "v=<随便改>&ammostrip=12&ammoms=60&ammosc=1&ammoskip=1.4&ammogift=buddy&buddy=6" /tmp/f.png'
```
- `ammosc=1` 原尺寸；`ammostrip` 格数（≤12）、`ammoms` 每格间隔、`ammoskip` 先快进几秒；`ammogift=buddy|bestie` + `buddy=<组号>` / `bestie=<组号>` 召你那一组；`ammogift2=bestie` 两边同时。
- 输出 `/tmp/f.png`（胶片）+ `/tmp/f.json`（每格你的人画的是哪一帧，格上也打字），并打印 console error（**必须是空的**）。
- 进场：`ammoskip=0 ammoms=70`；出手：`ammoms=50~60`，skip 到出手前（看 json 找）；待机：`ammoms=160`。
- 两个量漂移用的诊断参数：`noshake=1` 关命中震屏（震屏把整个角色层晃，最多 30px）；`trioswing=0` 秋千在场不摆、整体不前后倾（只剩换帧本身）。

### 8.3 量锚点漂移

```bash
python3 v14/trio/tools/drift.py f.png 12 web/assets/trio/B21_sakura.webp 555x208 4 0 330,150,440,200 712,1330,0.95 300.1,199.2 16 \
  id=B21 names=idle,wind,throw,follow,dive,flop,slide,idle2
```
参数：胶片、格数、图集、格大小、列数、参考帧下标、**量的框**（格内像素）、at、anchor、搜索半径、id / names（按 f.json 每格取那一帧当模板）。
量法：取图集里那一帧"不动部位"那块 + alpha 当遮罩模板，到引擎按 at/anchor 算出的位置 ±R 里找（只比人身上的像素，背景滚、东西飞过都不影响）。
- **框选紧贴锚点的那一截**（樱木贴地的肚皮到大腿 `330,150,440,200`、格格压在座板上的臀底 `60,188,130,214`）：呼吸绕锚点胀缩，框离锚点越远读数里呼吸越多。
- 框里不能有会被别的东西盖住的地方（格格膝上重新冒出来的绣球连流苏会盖到臀侧，框第一版到 x 150 就被骗出 13px）；残差比别的格大一个数量级 = 被挡了，看图确认。
- 秋千的人加 `trioswing=0` 拍；不加的话要给 `pivot= rot=`，但一小块离转轴 700 多像素时转一点和平移一点分不开，dx 不可信。
- 进场帧（在动）、`（不在场）` 的格不算。
