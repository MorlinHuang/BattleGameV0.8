### 4.6 给引擎的统一做法（对照单）

1. **投掷实物（15 名引擎可解：B6 B9 B17 B18 G5 G6 G7 G10 G11 G12 G15 G16 G18 G19 G20）**：
   - 不再用"中点控制点 + arc"拱一条弧。改成真弹道：出手方向 θ = 出手前一帧 → 出手帧的手位移方向（cfg 加 `atk.dir` 按帧写，或由 hold 逐帧手位自动算），g 取全局常量（建议 1800~2400 px/s²）。按目标反解初速：
     - v² = g·dx² / (2·cos²θ·(dy + dx·tanθ))；
     - 飞行时间 T = dx / (v·cosθ)。
   - 后排的人用同一条抛物线检查头顶那几列（同 over 的三列）。
   - 若 dy + dx·tanθ ≤ 0（目标在出手射线上方）或越不过头顶，说明这一帧物理上扔不到，不要偷偷拐弯，回退到美术补帧名单。
2. **绸带 / 鞭（G9、G13）**：第一节方向 = 手臂方向，用弹簧链或三次贝塞尔（P0 → P0 + dir·L/3 → … → 目标）弯过去；软的东西可以弯，硬的不行。
3. **B20 喷雾**：雾团首段沿嘴的朝向（水平）喷出，按重力落到目标，同第 1 条。
4. **B13 飞剑**：残影沿路径切线旋转，剑尖朝飞行方向。
5. **斩痕（B23、G14）**：
   - slash.ang 按挥向写：G14 往右下劈，弦线往右下约 45°，从右上往左下划；B23 刀尖往左上扫。
   - 从刀尖甩出剑气沿挥向飞到落点再展开，不在落点凭空出现。
6. **B5**：atk.from 按出手帧写到棍梢；**G5**：fire 标到 release 帧。
7. **光束、伸长的肢体、肢体残影、指尖能量**：引擎不要做"先沿手出去再拐弯"——那就是用户截图里的"拐弯"。这些人在 4.4 的"需美术补帧"里，等新帧。新帧没到之前，引擎能做的只有让光束 / 管子 / 残影从手的正前方出发。
