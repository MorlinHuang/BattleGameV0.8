# 绿茶妹妹 · 在场循环视频（即梦 Seedance，首尾帧模式）

用途：同真相女神 / 白娘子 / 嫦娥：出场视频放完后她在场的那段，用一段原地循环的透明视频顶替立绘。
聊天气泡（从手机屏幕抛出去）、身后的粉光、底下的奶盖泡泡海都由游戏画，视频里只要她本人和手机（游戏拿手机对位）。

## 设置
- 模式：**首尾帧**，首帧、尾帧都传 `绿茶妹妹_循环_首尾帧.png`（1200×1600，3:4，比例按图自动适配）。
  原立绘 v14/sister/pose/P3a.png 兔耳尖离画框上沿只有 13 像素，抠出来缩 0.9 居中放到纯绿 3:4 画布，四周留足。
- 时长：选最长。
- 关不掉音频：不写任何说话 / 嘀咕 / 碎碎念的描述；她原本就是手背掩嘴，提示词要求"手不离开嘴边、嘴唇闭合"，反向压张嘴 / 口型。
- 绿幕：奶白毛衣、粉手机、粉脸颊、草莓胸针上品红幕都会被抠掉一截；她身上没有绿。
