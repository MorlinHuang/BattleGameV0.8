# 拉扯动作试点 · aK（女主赢、男生跪着被拖）· 即梦 Seedance

用途：试一试用生视频代替现在的"逐帧生图"拉扯动画。现在 aK 档是 1 张原图 + 7 格后退步态（每格只重画女生的腿）+ 3 张男生挣扎帧拼起来的，
每格单独生成，腿粗细、短裤、拖鞋格与格之间对不齐，接缝要靠光流去修。视频模型一次生成连续动作，前后帧天然连贯，这是这次想验证的。

**游戏里怎么用**：不是直接放视频。我把视频逐帧抽出来、抠掉品红背景、按手机位置稳住，挑出一个完整的"后退一步 + 再一步"做成循环，
替换现在 aK 的 8 格步态。播放速度仍跟着两人在长卷上被拖了多远走（拖得快走得快、停下就停、对面反拽就倒着播），所以**视频本身的快慢不重要，动作连贯、人不变形才重要**。

## 一、生成参数

| 项 | 设置 |
|---|---|
| 模式 | **首尾帧**，首帧、尾帧都传同一张 `aK_首尾帧.png` |
| 比例 / 分辨率 / 时长 | **16:9** / 1080P（没有就 720P）/ 5 秒（能选 10 秒更好，我能多挑几个步子） |
| 音频 | 关 |
| 运镜 | 不勾"随机运镜" |
| 数量 | 每版 4 条，全部交来，我量完再挑 |

## 二、画面元素规划（哪些进游戏）

| 元素 | 进不进游戏 | 怎么保留 / 约束 |
|---|---|---|
| 女生全身（头发、睡衣、兔子拖鞋） | 进 | 品红色键抠像；外观必须跟首帧一致 |
| 男生全身（睡衣、短裤、黑猫拖鞋） | 进 | 同上 |
| 手机 | 进 | 两人各抓一端、横着、屏幕朝镜头；我用它当每帧的定位锚点，**手机不能被手完全挡住、不能换手** |
| 地板、影子、灰尘、速度线 | **不要** | 地板是游戏的长卷、接地影和拖痕游戏自己画；视频里出现就得一帧帧擦 |
| 汗珠、怒气符号、气泡 | **不要** | 游戏的特效层会画 |

日系赛璐璐动画风格，二次元高质量作画，干净的描边，色彩鲜艳。与首帧为同样的两个角色、同样的服装和拖鞋，人物外观、身材、腿的粗细全程严格保持一致。纯品红色背景（#FF00FF），背景全程纯色不变，没有地板、没有影子、没有任何场景、光效、粒子。

## 四、挑片时看什么（交全部 4 条也行，我会逐帧量）

- 两个人从头到脚始终完整在画面里，没有出画、没有被切；
- 女生是**一步一步倒退**（能看到腿交替抬起、落下），不是整个人平移；
- 男生始终跪着，没有站起、没有趴下；
- 两人的脸、衣服、拖鞋、腿的粗细从头到尾不变；
- 手机一直横在中间、两人各抓一端；
- 背景始终纯品红，没有地板和影子。

## 五、交片后我做什么

1. 逐帧抽出，品红色键抠像（沿用档 4 循环视频的抠像和去毛边：make_loop.py）。
2. 按手机位置把每帧稳住，再按首帧换算回原图坐标：原图 (x, y) → 参考图 ((x−88)×0.95369+306, (y−120)×0.95369+144)。
3. 量女生每只脚的落地时刻，切出一整个步伐循环；量腿宽，跟原图比，跟现在线上的 0.97~1.11 比。
4. 做成和现在 aK 步态同一套格式，挂在一个网址参数后面（不影响正式页），你可以并排对比。效果好再决定其余五档、挣扎和档间过渡要不要都换。
