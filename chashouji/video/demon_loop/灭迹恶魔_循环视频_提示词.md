# 灭迹恶魔 · 在场循环视频（即梦 Seedance，首尾帧模式）

用途：同真相女神 / 白娘子 / 嫦娥 / 绿茶妹妹：出场后她 / 他在场的那段，用一段原地循环的透明视频顶替立绘。
喷出去的紫色撤回烟雾、罐尾的尾焰、身后的烟和裂光、角上的光、底下的法术潮都由游戏画，视频里只要他本人和罐子（游戏拿它对位）。

## 设置
- 模式：**首尾帧**，首帧、尾帧都传 `灭迹恶魔_循环_首尾帧.png`（1200×1600，3:4，比例按图自动适配）。原立绘贴着画框边，抠出来缩 0.86 居中，四周留足。
- 时长：选最长。
- 关不掉音频：不写任何说话 / 念经 / 念咒的描述，只写"嘴唇全程闭合"，反向压张嘴、说话、口型。
- 背景用纯绿：他一身暗紫、酒红，品红幕会把翅膀和衬衫抠穿（立绘就是绿幕）。

## 挑片看什么
- 首尾两帧几乎一样；全程露全身、不碰画面边缘；
- 罐子不转、不挪，罐口不冒东西；翅膀张到最大时翼尖也不出画；
- 背景全程纯色，没有冒出烟雾、光点、文字；
- 嘴一直闭着；脸、衣服没变。
