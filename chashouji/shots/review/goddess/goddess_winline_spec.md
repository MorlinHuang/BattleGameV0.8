# 用户需求（2026-09-27）：终点线 + 真相女神升级
原话：「现在男女生赢得地方太不明显了，需要在双方赢得地方，地上拉一条明显的线。真相女神的位置可以在向上一些，不要和闺蜜在一起，整体可以再大一些，占领女生这半边的一般区域，可以把特效做的更炫，整个边缘外发光，像一个真正的女神，然后喷出的特效范围需要更大些，更夸张，让她符合一个最高级礼物的定位」

## 一、终点线
**现状**：判胜是手机中点被拖到 ±NUM.END=30 米（main.js:114，折合世界 x = center ∓ 1640px）。地上什么都没有，只有顶上的距离条。镜头跟着两人走，终点在离它 ≤480px（约 8.8 米）时才进画面。

**示意**：`winline_sheet.png`，左为查岗党 pos=+25，右为灭迹党 pos=−25；单张原大 `winline_g.png` / `winline_b.png`。
- 地上铺一条终点方格带：队色与黑相间，从墙根 y≈1150 铺到 1334（再往下是评论区），带轻微透视。
- 终点处立一道竖直**光幕**：从地面往上约 560px，下实上虚，中间一条白芯。光幕顶上写「终点·查岗党胜」/「终点·灭迹党胜」。
- 队色：查岗党绿 (40,200,100)，灭迹党红 (230,50,60)，跟 HUD 两边的颜色一致。
- 位置：屏幕 x = MID + (终点世界 x − FX.camX)，跟背景一起卷动。
  - 女生终点世界 x = WORLD.center − NUM.END·P.pxPerM，男生是 +。
  - pos=±30 时手机正好压在线上，读出来就是"把手机拽过线"。

**实现要点**：
- 方格带画在背景层 `drawWorld` 之后、人物之前（bctx）。
- 光幕画在 cctx 里、人物之后，要半透明，不能盖住人。示意里光幕叠在人身上，只是为了看颜色。
- 接近终点时（离线 < STAND_AT，也就是现有"终点透红呼吸"的那个时刻），光幕和方格带跟着一起呼吸加亮。
- 终点还没进画面时（离线 > 8.8 米），在屏幕对应的那一侧边缘加一个小箭头「终点 ← 12m」，贴在地面高度。否则大半局都看不到线。

## 二、真相女神
### 已验证：只放大、抬高，现在这套"整身转"不成立
在引擎里临时改了配置（`engine_spray_try.png`，脚本是 /tmp/rv/god.py，源码没动）：TRUTH.rows 1.25、perch (120,760)、aim.lo −1.15。
- 结果：人一放大一抬高，为了让罐子朝下对准男生的脸，整个人要前倾 0.7~1.07 rad。身子全部甩出屏幕左上角，画面里只剩一根罐子。
- 喷雾放大那部分效果很好，可以直接用：fluid.spread 0.28、rate 220、life 1.15，TRUTH_FX r0 30 / r1 110，flare [40,64]，miss 150。雾锥盖住男生整个上半身，p95 / p5 都打得中。

### 建议方案：`goddess_compare.png`（左现状、右建议），`goddess_s125.png`，脚本 `mock_goddess.py`
- **大小 / 位置**：s≈1.25，身高约 560px，占女生半边的左上区域 x 0~460、y 210~710。脚底约 (80,700)，在女主头顶以上 150px，跟站在地上的闺蜜（y>900）完全分开。
- **只转上身**：腿保持原图竖直，上身连罐子绕腰 [136,184] 转。
  - 这一版要转约 1 rad 才对得准脸，腰弯得很厉害，读成"扛着罐往下倒"，不够女神。
  - **根本解是重出一张女神姿势立绘**：身体竖直悬浮，头发和短裙往上飘；罐子夹在腋下、枪口朝右下约 40°。这样瞄准时只需要 ±0.25 rad 的小幅调整。
  - 用 chashouji-art 的品红幕布流程出图，保留现在的服装和脸。
- **女神外发光**（示意里已经做了，读得出来）。按"明亮底图上发光靠色相"的原则，靠三层有色光，不用 lighter：
  1. 剪影外扩 3px、模糊 3，白金 (255,252,220)；
  2. 外扩 9、模糊 10，金 (255,225,120)；
  3. 外扩 21、模糊 26，橙金 (255,170,40)。
  - 另外两样：身后 16 道放射状金色光芒，径向渐隐，缓慢旋转；头顶一个金色光环。
  - 引擎实现：把她画到离屏画布，用 `ctx.filter = 'drop-shadow(...)'` 叠三层，这个在页面里已验证可用；或者 build 时把光晕烘进贴图。光芒、光环在运行时画。
- **喷雾**：用上面引擎验证过的放大参数。命中环加一圈金色外环，跟外发光统一。
- **名字条**：她的新位置在 y 210~710，现在的名字条中线 y=330（main.js INTRO.y）会压在她身上，要挪到 y≈780，也就是她脚下、两人头顶之上。

## 立绘出图要求（交给出图的人）
- **姿势**：竖直悬浮、面朝右，身体基本直立，不前倾也不弯腰。双腿并拢或一前一后微屈，**不要叉腿**，旧图后腿出画就是叉腿造成的。靴尖朝下，读成"浮着"而不是"站着"。
- **罐子**：还是那罐「真相喷雾」。双手托在身体右侧，罐身斜向右下约 35~45°，罐口在人物右下角。**罐口的最低点就是整张图的最低点之一**，出图时让罐口和靴尖大致同高，都压在上面的 780 线以内。
- **女神元素**：头发、短裙、飘带往上飘，给出失重感；保留现有的青柠赛车服、白色过膝靴、金发绿挑染和脸。光环、放射光芒、外发光**不画进立绘**，由引擎画，好控制强度，也好做动画。
- **构图比例**：画布宽高比约 1:1.05，人物加罐子的外框约宽 480 × 高 540（引擎里 s=1 时的像素）。
- **分层**：一张完整立绘，另切一层"罐子 + 双手前臂"。瞄准时只让这一层绕肩膀小幅转 ±0.25 rad，人不动。
  - 要在图上标出：肩膀转轴、罐口 muzzle、罐尾（尾焰挂点）。
- **出图流程**：chashouji-art 的品红幕布、抠像、去溢色流程，同 v14/truth/make.py。概念参考 concept/gift-spray/ 里用户认可的两张。
