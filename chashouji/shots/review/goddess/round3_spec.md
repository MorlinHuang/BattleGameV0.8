# 第三轮需求（2026-09-27）
原话：「终点的概念是对的，但物件不符合整个美术画风，可以换个更搭场景的。手机现在发光，一眼看上去反而不像手机，可以在优化下。另外男生这边可以召唤一个男恶魔，对应对方的女神」

## 一、终点线：换成房间里本来就会有的东西，画进背景
现状：线上是方格带 + 竖直光幕 + 「终点·X党胜」字样（截图 /tmp/t5 → `goddess/winline_live.png`）。概念对，但那是 UI 贴片，跟手绘房间两层皮。
建议：**用局部重绘直接画进房间背景图**。画风天然一致，也跟着背景卷，引擎不用画线。
- 卧室（女生终点，room0 里世界 x = center − 30·pxPerM ≈ 626）：地上一条**粉色长毛地毯走廊**（runner），从墙根一直铺到画面下沿；地毯两侧边缘缠一串暖白**星星串灯**。卧室墙上本来就挂着串灯，是同一套东西。
- 电竞房（男生终点，≈ 3906）：地上一条贴地的 **RGB 灯带 / 发光电竞地垫**，颜色取房间里现成的青→品紫霓虹。
- 宽度要够"明显"：地垫、地毯宽约 70~90px（墙根处）→ 120~150px（画面下沿），带透视。示意 `goddess/winline_v2.png` 里只画了细线，方向对但太细，只用来看配色。
- 引擎只做两件事：
  1. 快到终点（STAND_AT）时，让这一块跟着"终点透红呼吸"一起亮一下。烘好的发光层单独出一张图，用 alpha 做呼吸。
  2. 删掉现在的竖直光幕和「终点·X党胜」字，胜负字留给结算。
- 出图：chashouji-art 的局部重绘流程。蒙版只盖终点那一条竖带，蒙版外的像素不动，跟房间接缝过渡段同一个做法。
- **顺带发现的一个问题**：pos=26 时画面下方同时出现「56m → 终点」和「终点 ← 56m」（`goddess/winline_live.png`）。近处那一头的终点已经在画面里，另一头 56 米的提示是噪音。建议只在对应终点不在画面里、并且距离 < 15 米时显示。

## 二、手机：发光过头，不像手机了
现状（`tablet/phone_v3.png` 左）：屏幕几乎占满整个机身，黑边框只剩 2px，外面一圈蓝光晕，拳头也染成蓝的。一眼读成一块发光的浅蓝色方块或游戏手柄，不像手机。
建议 A（`tablet/phone_v3.png` 中）：
- **去掉外光晕**：build.py:227 `GLOW.a` → 0。
- **去掉拳头染色**：build.py:228 `HAND_LIT.a` → 0。
- **加宽黑边框**：build.py:220 `SCREEN.w` 0.86 → 0.8、`SCREEN.h` 0.8 → 0.68，四周露出 3~4px 黑边，短边两头更宽。机身圆角要明显，外面有深色描边。
- **屏幕底色**从冷蓝渐变改成近白 (245,247,250)，屏幕"亮着"靠白屏和黑边的对比，不靠光晕。绿色顶栏和气泡保留。
- 加一道斜的玻璃反光（白色，透明度约 0.28）。短边黑框上加一个前摄小圆点。
- B（`phone_v3.png` 右）：在 A 的基础上加一圈 2px 很淡的白光。看不出比 A 好，**推荐 A**。

## 三、男恶魔：男生档 4，对应女神
- 位置：`ITEM_OF.R[4]` 从 `'photo'`（相框）换成 `'demon'`，相框那行留作备选。数值不动（SHOP.drop，push 600，power 4）。
- **镜像女神**：悬在右上，面朝左，从右上画外斜着飞进来。
- **硬约束（实测）**：男生站着时头顶最高 y 781（bK，其余站姿 794~823）。恶魔最低点（含武器、外发光）≤ **y 750**，最高点 ≥ y 190。可用高度约 560px，人物本体加武器 ≈ 500~520px，横向占 x 480~960。
- **形象**：
  - 帅气男恶魔，跟女神同一套画风，粗黑描边、平涂。
  - 小角、黑色蝙蝠翼、细尾巴；敞开的黑色衬衫或皮夹克，暗紫加酒红配色。
  - 竖直悬浮，翅膀张开，不叉腿。
  - 光环、外发光、烟雾不画进立绘；罐子加前臂单独切一层。
- **武器，对应「真相喷雾」**：一罐黑紫色巨型喷罐「一键清空」，罐口朝左下 35~45°，对准女生的脸。
  - 喷出暗紫色"撤回烟雾"，打中后从女生脸上蹦出「已撤回」「记录已清空」这类灰色系统提示小标签。
  - 气泡系统里已经有「对方撤回了一条消息」这种文案，正好呼应灭迹党的主题。
- **特效**（明亮底图上发光靠色相）：
  - 外发光三层：内圈品红 (255,120,220) → 中圈紫 (170,60,230) → 外圈暗红 (160,20,60)。
  - 身后一团缓慢旋转的黑紫烟雾加几道暗红裂光，替代女神的金色光芒；头顶是一对发光的角，替代光环。
  - 喷雾参数跟女神放大后的一样，颜色换成：托底深紫 (50,20,70)、雾身紫 (150,90,220)、亮芯淡紫 (230,200,255)。
- **出场**：全场压暗加名字条，跟女神同一套 INTRO。名字条用暗红配紫描边，名字建议「灭迹恶魔」。续送同样重播 ×N。
- **同屏**：女神和恶魔可能同时在场，一左上一右上，中间 x 460~500 不能重叠。两股雾在两人中间交叉，要看得清各打各的。
