# 档 4 女神 / 男神扩成每边三人（2026-09-28 用户定）

用户原话：「女神和男神礼物，也和闺蜜和哥们一样，最多出现3个。所以再设计两种女神，这次要稍微带点梗。可以使用一些知名角色做底子，但不能完全还原，防止版权纠纷。女神这边加一个美少女战士的主角水冰月，还有黑寡妇。男神那边新加个超人和杨戬」

- 女生档 4（查岗党）：真相女神（已有）+ 水冰月底子 + 黑寡妇底子。
- 男生档 4（灭迹党）：灭迹恶魔（已有，18c00c6）+ 超人底子 + 杨戬底子。
- 数值不动：每送一次档 4 召一个没在场的；满 3 人再送 = 给剩余时间最短的续一段，名字条重播「×N」（跟现在女神续送一样）。

审查角色不改代码，下面是给开发者的规格和落地后的复核判据。行号按 HEAD 18c00c6。

## 一、防版权的总原则（六个人都适用）

用户要的是"一眼看出在玩谁的梗，但不是那个角色"。做法：**保留轮廓和梗，换掉商标、名字、配色细节、演员的脸。**

| 必须避开 | 原因 |
|---|---|
| 原角色名字（水冰月 / 月野兔 / Sailor Moon、黑寡妇 / Black Widow / 娜塔莎、Superman / 克拉克）出现在画面或名字条上 | 角色名和商标 |
| 标志性徽章原样出现：超人胸口 S 盾徽、黑寡妇红色沙漏、神盾局鹰徽、水冰月额头月牙、胸前变身胸针 | 商标，维权最积极的就是这类 |
| 照着某个演员的脸画（斯嘉丽、亨利·卡维尔、克里斯托弗·里夫、焦恩俊） | 肖像权，比角色版权更容易出事 |
| 某一版影视里的具体造型原样照搬（例如杨戬照《新神榜：杨戬》2022 的造型、照 1996 电视剧剧照） | 神话人物是公版，但某一版的造型设计不是 |

生图提示词里**不要写原角色名**（写了模型就往原版画，而且会带出徽章），只写外形描述；出来的图对照上表自查一遍。

画风统一：跟 `truth2_up.webp`、`demon1_up.webp` 同一套（赛璐璐、粗描边、单层、三层外发光烘进贴图），走 v14/truth/make2.py、v14/demon/make.py 同样的管线（品红幕布抠像，见 chashouji-art）。

## 二、六个人

### 女生档 4（查岗党：把真相查出来）

**① 真相女神（已有，不动）** — 金色外发光、「真相喷雾」、青柠雾。

**② 月亮查岗使（水冰月底子）**
- **梗**：「代表月亮，查你手机！」（改自"代表月亮消灭你"）。命中时从男生脸上蹦「代表月亮查你！」「已读」「查到了」。
- **保留**：金色丸子头 + 两条超长双马尾（最关键的剪影）、水手领短裙、及膝长靴、魔法少女手持短杖、摆 pose。
- **要改**：
  - 配色：不用原版的蓝领、红蝴蝶结、白上衣，改成薄荷绿领 + 粉色大蝴蝶结。薄荷绿是查岗党的颜色，也跟真相女神的青柠区分开。
  - 额头：不画月牙，改成一颗手机形状的小宝石。
  - 胸口：不画变身胸针，改成爱心形状的锁。
  - 短杖：顶上是放大镜套爱心（查岗的道具），不是原版的月亮杖。
- **攻击**：短杖朝右下，喷出一股**粉色爱心 + 小月牙**的光流，形状跟现在的雾锥一样，只换粒子。
  - 按明亮底图的规矩：爱心本体用饱和粉 (255,90,160)，加暖黑描边 INK (58,44,38) 描 3px，否则在浅绿墙上看不见。月牙用暖金 (255,200,60)。
- **出场**：从左上画外转着圈落下来，脚下带一圈粉色缎带光环，落定时"叮"一下闪出一个爱心冲击环（代替女神的青柠冲击环）。
- **名字条**：「月亮查岗使」，条色粉 (255,110,180)、字色浅粉。

**③ 黑蛛女特工（黑寡妇底子）**
- **梗**：特工追踪。吊着一根丝从天花板降下来，就像电影里"吊威亚潜入"的镜头。命中时蹦「已定位」「行踪已锁定」「天网恢恢」。
- **保留**：暗红色齐肩短发、黑色紧身作战服、腰带、腕部装置、特工冷脸。
- **要改**：
  - 腰带扣：不是红沙漏，改成红色的手机定位图钉。
  - 臂章：没有任何组织标志。
  - 脸：不照任何演员画。
  - 头发：不做原版电影的大波浪，做利落的齐肩短发。
- **攻击**：腕部装置朝右下射出**一张蛛网**，网住男生的脸和手机，网上挂着红色定位图钉。
  - 白丝在浅色底图上会消失，所以丝用暗红描边 (120,20,30) 加白芯。网张开时有一圈红光。
  - 这是网状、会贴在脸上停一会儿的东西，不是雾。
  - 注意不要画成蜘蛛侠的蛛丝发射器：蜘蛛侠是手心朝前、两指按下。这里用的是腕表式的钩索装置。
- **出场**：不用火箭。从屏幕顶上吊一根丝降下来，丝由运行时画一条线连到画面顶部，悬停时人随丝轻轻摆动。离场时收丝往上拉走。
  - 身体始终竖直，**不要倒挂**。倒挂时头会是最低点，要保证 ≤ y780 就得整个人往上抬，站位更紧。
- **名字条**：「黑蛛女特工」，条色暗红 (200,40,60)、字色浅红。

### 男生档 4（灭迹党：把证据删干净）

**④ 灭迹恶魔（已有，不动）** — 品红紫外发光、「一键清空」、撤回烟雾。

**⑤ 内裤外穿侠（超人底子）**
- **梗**："超人内裤外穿"这个老梗做成名字，红内裤穿在外面要画得显眼。武器是眼睛发射热射线，把聊天记录烧成灰。命中时从女生脸前蹦「已粉碎」「永久删除」，同时飘出烧焦的气泡碎片。

  - 腰带：不要原版那种黄色。

## 三、同屏三人的站位（示意 `trio_layout.png`）

现在每边一个人，缩放 s 0.95、身高约 590px，已经占满自己那半边的上半屏（女神 x 29~409、恶魔 x 572~960）。三人同时在场塞不下，得重新排。

**做法：1 人时用现在的大站位；2~3 人时，全体滑到斜线上的三个槽位。**

| 槽 | 靴底（女生侧） | s | 画面上占的范围（按 truth2 贴图量） |
|---|---|---|---|
| 1 前（左下） | (100, 740) | 0.66 | x 2~266，y 348~758 |
| 2 中 | (215, 626) | 0.60 | x 126~366，y 270~641 |
| 3 后（右上） | (330, 517) | 0.55 | x 249~469，y 190~530 |

男生侧是镜像：x 换成 960−x，靴底再上移 25（男生站着时头顶更高，最低点要 ≤ y750）。

示意图里验证过的几点：
- **六张脸都露着**：每个槽位的脸都在前一个槽位的上沿之上。例如槽 2 的脸在 y≈308，槽 1 的上沿在 348。
- **六个喷口都露着**：喷口在身体右侧，槽位是往右上错开的，所以喷口不会被别人挡住。
- **喷射方向**：三人是沿"喷射方向的垂直线"排开的，所以每股都往右下喷，不会穿过自己这边另外两个人的身体。
- **中线**：女生侧最右到 469，男生侧最左到 491，中间空 22px，不会重叠。
- **最低点**：女生侧 758 < 780；男生侧 733 < 750。

**排队规则**：新来的人占 1 号前排（最显眼，也跟名字条对得上），在场的人依次往后挪。
- 换槽位时，位置和缩放都用 0.4 秒的三次 Hermite 平滑过去，做法跟 crew.js:120 离场召回那段一样，位置和速度都不能跳。
- 从 2~3 人降回 1 人时，剩下那个人滑回大站位。

**要改的代码点**
1. crew.js:113 `o.perch()` 改成 `o.perch(b)`，同时让 `b.s` 可以随时间变化。现在的 s 是召唤那一刻定死的（crew.js:100）。
2. main.js 加一个每边一份的槽位管理：记录谁在哪个槽、目标位置和缩放。`TRUTH_PERCH`（main.js:1980）和 `DEMON_PERCH`（main.js:1997）改成从这里取。
3. 三个人贴图的比例不一样，槽位表是按 truth2 量的。新立绘出图时，**人高 + 武器的包围盒要跟 truth2 差不多**（宽约 400、高约 620，贴图像素）。出来以后，每个人的最低点和中线余量都要按上表再算一遍。

## 四、引擎怎么接

每个人的武器都不一样（雾、爱心光流、蛛网、射线、天眼加马赛克），**不能用 skins 换皮**。skins 要求同一个裁边框、同一套 foot 和 muzzle（crew.js:12）。

- 每人一份独立的 Crew 配置，照 `TRUTH` / `DEMON`（crew.js:633 / 695）的写法。
- 每边用一个组调度起来：b37c821 里的 `CrewGroup(members)` 可以直接拿回来用，它会挑一个没在场的成员召唤。每个成员 `max: 1`，组合起来最多 3 人；满员时对剩余时间最短的那个 `renew`。
- `CREW.truth` / `CREW.demon`（main.js:1132）换成两个组。`GIFT.truth` / `GIFT.demon` 保留一个名字，名字条按成员各自取。
- 出场压暗和名字条：`STARS`（main.js:2139）现在每边绑一个 crew，要改成每边绑一个组、按成员取名字和颜色。压暗取场上最深的那个（现在已经是这样）。
- 诊断参数：`?skin=` 或新加的 `?g4L=0|1|2&g4R=0|1|2`，用来强制召唤某一个人，胶片要能一个一个单独拍。
