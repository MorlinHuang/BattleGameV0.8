# 房间衔接处不自然（用户 2026-09-27）

原话：「当前卧室与两个房间连接之处，过度的特别不自然」
证据是按 `drawWorld`（main.js:1369）拼法，把 room0/1/2.webp 首尾相接后，截取接缝左右各 480px：
- `bed_living.png`：卧室 | 客厅，接缝在世界 x=1558（图顶红线）
- `living_game.png`：客厅 | 电竞房，接缝在世界 x=3045

## 看到的问题（两处接缝相同）
1. **一条竖直硬切线贯穿整屏**：从天花板一直切到画面最底，墙、踢脚线、地板都在同一列突变。地板在墙前面，本来是同一个空间，不可能被竖着切开。这是最刺眼的一条。
2. **地板光影对不上**：卧室地板是斜向的窗光条，客厅是树叶影，电竞房是紫光反射，色温也不同，三块在同一条线上硬接。
3. **门只有半扇**：`build.py` 的思路是"一扇门取两张图各一半"（docstring 第 10~14 行），但实际切完后门洞右侧紧接着就是隔壁的墙，右门框被 `CUT_LIVING_L=75` / `CUT_BOY_L=140` 切掉了，门读成"墙上一个缺口"。
4. **门洞里的东西和门外重复**：卧室门洞里透出的是客厅的梳妆台、镜子、郁金香和粉拖鞋，而门洞右边紧挨着的客厅图里，同一个梳妆台、同一双拖鞋又画了一遍，距离不到 100px。电竞房那边同理：门洞里是显示器和桌子，门外马上又是一套。
5. 墙面颜色直接从粉跳到绿、从绿跳到深紫，中间没有墙角、墙垛这种有厚度的东西来承接。

## 根因
三张房间图是分开生成的，每张都把自己画成一个完整、光照独立的房间。拼接只做了"找门切开"，接缝处没有任何一段是专门为"两个房间之间"画的。门洞里透出的内容也是各自想象出来的，所以跟隔壁图对不上、会重复。

## 建议（二选一，推荐 A）
**A. 接缝处各出一段"过渡段"（需生图，一处一张）**
- 以接缝为中心，各取左右 300px 拼成一张约 600×1707 的底图，中间约 260px 做蒙版，局部重绘成：一段有厚度的**隔墙墙垛 + 完整门框**（左右门框都在），门开着，门洞里是暗一点、远一点的对面房间（不画具体家具，避免跟门外重复）；**地板在门槛处有一条门槛压条**，两侧地板各自延续自己的光影，在压条处收住。
- 蒙版外的像素保持不变，所以左右两张房间图一个像素都不用动。build.py 把过渡段盖在接缝上即可（room 宽度不变，`world.json` 的 rooms / center 都不变，距离条和判胜不受影响）。
- 提示词沿用 chashouji-art 的品红幕布、局部重绘流程；卧室侧要写清粉墙、客厅侧绿墙，门框统一白色。

**B. 不生图的补救（效果差一档）**
- 接缝处盖一根全高的白色门框立柱贴图（约 40px 宽，从天花板到地板线），遮住墙上的竖切线。
- 地板线以下，两侧地板在接缝左右各 120px 里做横向渐变融合，去掉地板上的硬切线。
- 门洞里重复的梳妆台、显示器涂暗或模糊掉。
- 这样能消掉硬切线，但墙面颜色的突变和"半扇门"还在。

## 落地后复核
- 用 `?p=50&pos=<米>` 把镜头停到接缝正中截图（卧室门 `dA` / 电竞房门 `dB` 见 main.js:1542~1543）。
- 看拽着走经过接缝时背景滚动是否连续，过渡段有没有和两侧错位（每 16ms 一帧的胶片）。
