- **G26 蝴蝶群聚成一团**（`web/trio.js` launch：`n` 颗只在弧高 ×0.8~1.2 上随机）：5 只蝴蝶从同一出手点、几乎同一条路飞，`F_g26_atk` 格 4~7 读成一小团。建议引擎给 `n > 1` 加散角 / 出手时刻错开（如 `spread`、`stagger` 字段）。
- **G30 "绿色螺旋光"只能画成直光束**：beam 没有螺旋 / 缠绕的画法；现在是绿色直光 + star 命中。建议 beam 加 `twist: { n, amp }`（沿光束画两条相位相反的正弦细线）。
- **onHit 'wear' 只画平面 prop**（`trio.js` 959 行一带）：3D 转盘的道具要挂在头上得另出一张平面图（G25 针筒、G28 呼啦圈都是从图集取一格存成 `assets/world/trio_g*_*.webp`）。引擎可以改成有 atlas 时取某一格画。
- **动作条里个别格头画大 / 画小 6~9%**（G30 idle、G28 follow），或两腿站位变了（G27 wind / follow、G29 follow）：处理见各人 prompts.md；以后提示词里可以加 "head exactly the same size in every cell"。
