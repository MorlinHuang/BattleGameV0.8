# 精美1：P6 出手补帧 + P7 待机补帧 —— 单人工作说明（给子任务用）

你负责**一个哥们角色**（目录见派单）。目标：在现有图集里补 3 张帧，让出手和待机不再像幻灯片。
仓库 `/workspace/art/chashouji`，在 `v14/trio` 下干活。先读：
- `docs/三人组角色规范.md` 第四、五节（生图模板、frames.py 切帧 / 配准 / 打图集）；
- 你的角色目录里的 `frames.json`、`prompts.md`（有的话）、`raw/` 里的动作条；
- `v14/trio/tools/frames.py` 文件头（frames.json 每个字段的意思，尤其 `scale_by` / `scale_ref` / `loose` / `fixed`）。

## 要补的帧（帧名固定）

| 帧名 | 放在哪 | 画什么 |
|---|---|---|
| `swing` | wind → throw 之间 | **出手瞬间的前半拍**：手臂正从蓄力位置往前抡、在头顶 / 肩前（比 wind 更往前、比 throw 更往后），身体明显前倾，头发、衣角、围巾、袍摆**往后拖**（和运动方向相反）。手里的道具引擎画，手型照 wind 的握法（as if holding …），**手里空着** |
| `thru` | throw → follow 之间 | **跟随**：东西刚出手，手臂顺势甩过身体到最低 / 最远，重心压在前脚，头发衣角**往前甩**（惯性），表情还在用力 |
| `idle2` | 待机第二张 | 和 idle **同一站姿、同一脚位**，只做一个小动作：换重心（胯换边）、眨眼闭眼、挠头、整理帽子 / 衣领 / 头盔、抖腿、打哈欠……挑最符合这个人性格的一个。**脚和不动的部位（frames.json 的 fixed 框）不能动** |

rush 型（双节棍 B5）另说：见派单。

## 怎么生（同一张底图 + 蒙版局部重绘，保证人不漂）

1. 从 raw 动作条里把**底图那一格**裁出来（`swing` 用 throw 或 wind 那格当底，`thru` 用 throw 或 follow 那格，`idle2` 用 idle 那格），
   贴到 1024×1024（或 1024×1536，看人的长宽比）的画布中间，画布底色 = 原条的幕布色（看四角；透明底的条铺品红 `#FF00FF`，
   人身上有粉 / 紫 / 品红的铺纯绿 `#00FF00`）。**人的大小不要缩放**（保持 raw 原像素），存 `raw/p6_<帧名>_base.png`。
2. 做蒙版（同尺寸 PNG，**透明 = 要重画、不透明 = 保留**）：
   - `swing` / `thru`：腰以上（手臂、躯干、头、头发、衣角会甩到的地方）全部透明，再往外扩到手臂会伸到的空白处；**腿 / 脚 / 坐骑 / 坐着的东西保持不透明**（它们就是 fixed，配准靠它）。
   - `idle2`：只透明小动作那一块（眨眼 → 只脸；挠头 → 一只手臂 + 头）。
   存 `raw/p6_<帧名>_mask.png`。
3. 调 `mcp__kf-image__generate_image`：`images: [底图]`、`mask: 蒙版`、`size` 和画布一致（1024x1024 或 1024x1536）。提示词要点：
   - 写"edit ONLY the transparent region"；把这个人的外观逐项写清（发型、服装、配色、道具），**不写作品名、角色名**；
   - 哥们**朝左**（facing LEFT）；日式动画赛璐璐、干净黑描边、饱和配色、成年人体型；
   - "hands EMPTY, as if holding a …"（道具运行时引擎画）；
   - 背景照原幕布色写死（pure flat magenta #FF00FF / pure flat chroma green #00FF00），no ground, no shadow, no text, no motion lines；
   - "bikini" + 跪姿 会被拒，换说法。
   一次 `n: 2~3` 挑最好的。生成图在 `/tmp/kf_generated_images/`（看工具返回）。**生成的图偶尔直接是透明底：直接用它的 alpha，别铺回幕布再抠。**
4. **出图自检**（看图）：脸、发型、服装细节和原帧一样；动作幅度够大（缩到游戏尺寸还看得出抡 / 甩）；手没有多出来的道具；没有地面、影子、字；
   腿脚和原帧完全一样。不行就改提示词或蒙版重生（最多重试 4 轮，还不行就在回报里如实写）。
5. 把选中的图存成 `raw/p6_<帧名>.png`（单格条）。

## 接进图集

1. `frames.json` 的 `sheets` 里每张新图加一条 `{"src": "raw/p6_<帧名>.png", "screen": "auto", "frames": ["<帧名>"]}`
   （透明底 screen 写 auto；幕布色就 auto 也能认）。
2. 原来条里已有的 `idle2`（是重画的 idle，几乎和 idle 一样）**改名 `idle0`**（不要删：`scale_by: sheet` 的条用最后一格当缩放参考），新的叫 `idle2`。
   若 `loose`、`graft`、`check`、`lift` 里写了 `idle2`，跟着改成 `idle0`。
3. 如果 `scale_by` 是 `sheet`：新加的单格条没有 idle 可参考 → 在这条上写 `"scale_ref": "<帧名>"` 会按它自己的头找缩放，通常可以；
   残差 / 头缩放异常就改用别的办法（比如这条按 fixed：看 frames.py 是否支持按条指定），把做法写进回报。
4. 跑 `python3 tools/frames.py <目录> build`（在 `v14/trio` 下），读打印：
   - **每一帧（含老帧）的配准残差 ≤ 2（输出像素）**；新帧的头缩放和老帧差 ≤ 3%；
   - 看 `preview/<名>_onion.png`：不动的部位是一个清楚的影子；看 `preview/<名>_yellow.png`：抠像无紫 / 绿边、无洞。
   - **记下 build 前后 `web/assets/trio/<名>.json` 的 `cell`、`anchor`、`frames`**（build 前先 `cp` 一份旧 json 到 `/tmp/<名>_old.json`）。
     如果 anchor 变了，算出 Δ = 新 anchor − 旧 anchor，回报里写清（总控要把 cfg 里所有格内坐标平移 Δ）。
5. 在 `preview/<名>_frames.png`（输出像素、50 px 格线）上量：
   - `swing` 帧里**握道具那只手的握点**（输出像素，和 cfg hold 同一坐标系）——只有派单说"有手持道具"的才量；
   - （可选）`thru` 帧手的位置。
6. 出一张对比图 `preview/<名>_p6.png`：一行 idle / idle2 / wind / swing / throw / thru / follow（输出像素、浅灰底），让总控一眼看动作连贯不连贯。

## 不许做的

- 不改 `web/trio_buddy.js`、`web/trio.js`、`web/main.js`，不 git add / commit / push，不部署到桌面，不 ssh。
- 不动别的角色的目录。

## 回报（最后一条消息，给总控）

逐条：
1. 三张帧做成没有（每张：底图哪格、蒙版范围、提示词全文、重试几次、选的是哪张生成图的路径）；
2. build 打印的残差表（全部帧）和头缩放；新旧 `cell` / `anchor` / `frames` 列表，anchor Δ；
3. `swing` 握点坐标（若要求）；
4. 对比图路径；你自己看对比图的结论（动作是否连贯、有没有走样）；
5. 有没有改 frames.json 的其它字段（逐条写）。

## 试点（B8、B28）踩出来的，务必照做

- **生图服务回来的图常是 1254×1254 透明底，而且整个人被重画**（蒙版只是软约束）。所以生成图必须**按 fixed 部位（靴子 / 屁股和腿 / 坐骑）模板匹配**，
  把它缩放、平移配回底图的大小和位置，再存 `raw/p6_<帧名>.png`。参考脚本 `v14/trio/buddy/p6ref/norm.py`（B8 专用写死的坐标，照思路改，用 tools/frames.py 的 gray / find / resize）。
- **上半身常被画大 4~8%**：量头 / 颅骨宽和老帧比，大了就绕胯点把腰以上缩回去（腰线上下 24px 渐变），参考 `p6ref/shrink.py`。新帧头大小和老帧差 ≤ 3%。
  frames.py 按头找的缩放对某些脸（光头、侧脸）不准，自检时手量头宽为准，回报写读数。
- **画在帧里的配件每帧都要在**（背上的钉耙、背箱、帽子、头巾、腰带挂件……）：新帧里少了或位置变了就重生，提示词里点名"the X on his back stays exactly as in the reference"。
- 新帧把画布撑大（拳头举得更高）会让 anchor 变——正常，回报里写 Δ 即可。
- 时间：每帧最多重生 3 轮；服务 502 / 熔断等一会再试，不算轮数。

## B28 试点更好的做法（新开工的照这个）

- **只取生成图的蒙版透明区贴回底图**（蒙版边上 6~10px 渐变，渐变带里生成图是幕布色的地方留原图），蒙版外全是原像素 —— 腿脚和原帧逐像素一样，不用再配准腿。
  生成图整体漂了位置 / 大小时，先按蒙版外的部位（腿）模板匹配把生成图对齐，再取透明区贴回。
- frames.json 新条上写 **`"scale_as": "<底图那一帧>"`**（tools/frames.py 已支持）：缩放照抄那一帧、只做平移配准，避免按头找缩放顶到边界把腿放大。
- 头被画大：把蒙版收小（idle2 只罩脸的椭圆，帽子 / 耳朵外缘留原图），头大小自然对上。
