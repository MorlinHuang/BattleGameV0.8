# 哥们新角色定妆清单（2026-09-30，按名单「变更（审查 1）」「变更（审查 2）」后的版本）

通用：日式赛璐璐、黑描边、成年体型、朝左、全身、**手里空着**（道具运行时单独画）。生图时用 v14/buddy/skate1.png 当风格参考图（B17 除外，见那一行）。
幕布：默认品红 #FF00FF；身上有粉、紫、品红的用绿幕 #00FF00。标「透明」的是生图直接给的 RGBA 透明底，直接用它的 alpha，不要铺回幕布再抠。
提示词里不写作品名、角色名。真人原型（B5 B6 B18 B27 B29）都写了 generic anime face，只借服装、道具和姿势。

脚本（都在 v14/trio/buddy/）：
- `sheet.py`：生成总览 ref/_sheet.jpg。先抠像再贴到灰底上，顺带检查抠像是否干净。
- `denoise.py B8 …`：处理透明底。把 alpha < 0.05 清零，再按包围盒外扩 16 px 原地裁切（审查 2）。已跑过的：B14 B15 B23 B27 B28 B6 B7 B10 B19 B26 B29；B8 已改成品红幕原图，不用跑。
- `b18_layers.py`：B18 人和扇子分两层合成（见 B18 那一行）。
- src/ 下放的是中间原图：B18 的人、扇原图，B15 重绘前的原图和蒙版。
