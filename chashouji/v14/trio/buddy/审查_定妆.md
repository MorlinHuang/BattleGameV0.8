# 哥们定妆图审查（审查 2，2026-09-30）

## 怎么审的

| 项 | 方法 |
|---|---|
| 辨识度 | 每张用 `sheet.py` 的 `load()` 抠像，裁到包围盒，缩到**高 300 px**，贴在游戏墙色（浅绿）上，只看人不看道具，能否一秒说出借的是谁。 |
| 抠像 | 算 `cut()` 的自检值：离轮廓 6 px 以内不算，再往里还半透明的像素数，下表记作"吃掉"；并把这些位置标红画出来看落在哪。另外贴到深蓝底上，看有没有幕布溢色。 |
| 碰边 | 检查 alpha 有没有碰到画布四边。 |
| 朝向 / 全身 / 成年 / 空手 | 看原图。 |

复现：在本目录重跑 `sheet.py` 里的 `load()` 就能得到同样的抠像结果。本轮的图在 `/tmp/rv/`：`grid300.png` 是 300 px 墙色总览，`eaten.png` 是被吃掉像素的标红图，`*_dark.jpg` 是深底图。这些是临时文件，重跑即得。

**抠像总评**：21 张都**没有幕布残色**。品红像素只出现在三处：B15 指尖紫光、B24 裤子粉条、B26 RGB 耳机，都是角色本来的颜色。"吃掉"的数量 7 张为 0~35；其余几张较大的，标红后都落在发丝、汗滴、剑光、闪电这类本来就该半透明的地方，身体上没有缺块。只有 B13 和 B16 的标红集中在要拆掉的特效上，见下表。

**透明底的通用提醒**（不算打回）：B8、B14、B15、B23、B27、B28 这几张直接给的透明底，四周有 alpha 很低的噪点，所以包围盒会撑到画布边。出帧前先把 alpha < 0.05 的像素清零，再按包围盒裁切，不然缩放比例会算错。

### 去噪核对（B6 B7 B10 B14 B15 B19 B23 B26 B27 B28 B29）

**结论：去噪没有吃掉边缘，裁切也没有切到人。**

1. **裁切留边**：每张主体离画布四边都正好 16 px（B14 左右是 14 / 7 px，因为原图就贴边）。
2. **残留碎块**：还剩的碎块全部在人物主体的包围盒里面（发梢、汗滴这类），没有一块在外面把裁切框撑大。
3. **和去噪前逐像素比**：拿第一轮存下的去噪前原图深底合成图 `/tmp/rv/*_dark.jpg` 对齐后比较，平均差 1.0~1.6（JPEG 噪声的量级）。差值超过 40 的像素，平均 alpha 在 250~253 之间，都在不透明的线条内部，是 JPEG 块噪，不在半透明的边缘上。**去噪前的原图在当时裁切框以外没有任何内容（0 px）**，说明没有切掉东西。
4. **最低不透明度**：被清零的只有 alpha < 13/255 的像素，这些叠到墙色上最多改变 5%，肉眼看不出。

B15、B27 这一步和原图差得大（平均 5.3 / 3.2），原因是图本身重做或改过，不是去噪造成的。
